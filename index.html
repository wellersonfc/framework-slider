Fundamentos · 01

O que é um framework?

É uma estrutura pronta para desenvolver aplicações com organização, padrões e recursos reutilizáveis.

Em vez de construir cada parte do zero, você parte de uma base definida.
EstruturaUma forma de organizar.
VelocidadeMenos repetição.
PadrõesMaior consistência.
estrutura + componentes

A diferença central

#

Framework

Fornece a estrutura da aplicação e orienta como as partes se encaixam.

  • Ex.: Angular e Next.js.
  • Na interface: Bootstrap fornece estrutura visual e componentes.
✳

Biblioteca

Entrega funcionalidades que você incorpora ao seu projeto.

  • Ex.: React e Font Awesome.
  • Pode ser usada junto com frameworks.

Observação: as fronteiras nem sempre são rígidas; algumas ferramentas oferecem recursos de ambas as categorias.

React · Interatividade com estado

A tela muda quando o dado muda.

src/App.jsx
import { useState } from 'react';

export default function App() {
  const [cliques, setCliques] = useState(0);
  return (
    <button onClick={() => setCliques(cliques + 1)}>
      Cliques: {cliques}
    </button>
  );
}

Conclusão

Você não precisa reinventar a web.

Aprender HTML, CSS e JavaScript é a base. Frameworks e bibliotecas ajudam a criar projetos mais rápidos, consistentes e interativos.
